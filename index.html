Game setup

Add players, set the bonus, then start. Digital dice are optional and each player can toggle them on/off during their own turns.
Rule used here: If Upper Total reaches the Bonus Target, the Bonus Points are added.

How scoring works in this app

Click a category to enter a score.

If a category must be eliminated, use Cross Out Category. Crossed-out categories display as X.

After a score is submitted, that player's scorecard locks for the rest of the turn. The next step is to click End Turn / Next Player.

If the player made a mistake, use Edit Mistake to correct that one entry before moving on.
